# Credits and references

The holder geometry and its four-parameter configurator were constructed for this project. No reference STL is distributed in this package. The spring-clip mechanism was inspired by these models:

- **DIN Rail Clip (side mount)** — Catatat / PlasticXYZ. https://www.printables.com/model/1753870-din-rail-clip-side-mount
- **Adjustable DIN Rail Clip (FreeCAD)** — kc2zgu / marauder156. https://www.printables.com/model/556742-adjustable-din-rail-clip-freecad

The reference models were identified during development as CC BY 4.0. Preserve these credits and source links when publishing. See https://creativecommons.org/licenses/by/4.0/ for that reference licence. This statement credits the inspirations; it does not select a distribution licence for the new package.

The new geometry adds a rear captive hex-head recess, a perpendicular bolt hole, selectable modular widths, symmetric rail-width adjustment and sheet-thickness adjustment with a constant support-to-latch gap. The design was iteratively refined using physical print feedback. CAD and configurator development used AI assistance.
