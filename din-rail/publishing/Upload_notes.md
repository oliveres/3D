## Files and description

1. Use the eight files in `STL/` as model variants. Each is a complete single part, already in print orientation.
2. Add the OpenSCAD file as the editable parametric source. The HTML configurator and other supporting files can be distributed in a ZIP of this package. Check the current upload form for accepted attachment formats.
3. Paste the text from `MakerWorld_description.md` into the model description.
4. Add the CAD renders and dimension diagram as supplementary illustrations. They are labelled as renders.
5. Select the distribution licence in the upload form and add the corresponding licence file to the package when chosen. No licence grant for this new work has been chosen on the author's behalf. Preserve the linked design credits.
6. Disclose the AI-assisted development where the upload form asks for it.
