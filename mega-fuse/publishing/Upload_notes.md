# Publishing notes

Use the current package only: DIN clip v4 and fuse carrier v3. The carrier STL is byte-for-byte identical to the accepted v3 model. Clip v4 extends both retaining lips 0.50 mm towards the centre.

Include the two STLs, the Bambu project if desired, and the ZIP containing the offline configurator and editable sources. The images are CAD renders, not photographs of a print. Check the current hook fit before describing it as physically verified. Preserve CREDITS.md and choose the distribution licence explicitly when publishing; no licence for the new design has been selected here.
